# Contributing

Thank you for helping improve this preliminary project.

## Reporting Issues

Please include:

- Operating system, Python version, and installation method.
- `pip show elitho` output or the exact ELitho commit.
- A minimal reproducible mask, parameter JSON, and step-by-step instructions.
- Actual and expected results. For physics issues, include the units and sign conventions used.

Do not upload confidential process data, restricted third-party files, or files that you do not have permission to redistribute.

## Pull Requests

1. Work from a dedicated branch and keep the change focused.
2. Add unit tests for computation changes. Physics-model changes should also include derivations, references, or numerical benchmarks when possible.
3. Run `pytest` and manually start the GUI to check the layout.
4. Preserve EUVlitho/ELitho attribution and license notices.
5. Clearly describe result-compatibility changes and remaining limitations.

By contributing, you confirm that you have the right to provide your changes under this project's MIT License.
